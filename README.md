# Olist E-Commerce Data Analysis

## 📊 Project Overview

This project focuses on analyzing **Olist E-Commerce data** to understand sales performance, customer behavior, order trends, and key business performance indicators.

The project uses **SQL, Excel, and Power BI** to clean, analyze, visualize, and present meaningful business insights from the dataset.

## 🛠️ Tools & Technologies

* **SQL (MySQL)** – Data analysis and KPI calculations
* **Microsoft Excel** – Data analysis and dashboard creation
* **Power BI** – Interactive dashboard and data visualization
* **GitHub** – Project documentation and version control
